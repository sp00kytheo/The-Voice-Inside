# The Voice Inside

> *A personal journaling application built with HTML, CSS and JavaScript.*

---

## 📖 About

**The Voice Inside** is a personal journaling application designed to help users express their thoughts, emotions and daily experiences in a simple, safe and organized way.

The project started as a school project and continues to evolve into a complete journaling application developed by **TH3O'S PRODUCTIONS**.

---

## ✨ Features

- 📝 Personal journal entries
- ⭐ Favorite thoughts
- 🔍 Search thoughts
- 📊 Mood statistics
- 🌙 Light / Dark Theme
- 💾 Automatic Local Storage saving
- 🔢 Character & word counter
- 📤 Export journal to a text file

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
